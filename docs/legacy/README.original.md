# Multi Idle

Aplicativo desktop Windows para organizar e executar sessões web persistentes e isoladas.

Este repositório começa pelo núcleo universal da versão 1.0. Integrações específicas ficam fora deste primeiro corte.

## Desenvolvimento

```powershell
npm install
npm run build
npm test
npm start
```
